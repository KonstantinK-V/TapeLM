# TapeLM — простыми словами (RU)

Кратко: **один продукт** (variant A) — curve encoder P1 + fp-память в одной геометрии. Ниже — стадии **213+** (freeze, W, canonical, decode, resolution) внутри той же системы, что и 192–205.

---

## Главное, что работает в variant A

**Память = отпечатки слов (fp)** с одного замороженного encoder P1.  
Пока **буквенный encoder (`arc_enc`) не трогаем**, fp не меняется — слоты и lexicon остаются valid.

---

## Stage 213 — заморозить весь `arc_enc`, учить только «верх»

- **fp слов:** не сдвинулся (практически ноль).
- **Минус:** если доучивать только на детских stories, падает точность на wiki-тестах.
- **Вывод:** для стабильной памяти — **держать `arc_enc` frozen**; домен лучше через **отдельный маленький адаптер**, не через перековку букв.

## Stage 214 — «свежие слова в контексте важнее старых»

- **Идея:** усреднять fp слов вокруг сущности с затуханием по расстоянию.
- **Результат:** **не помогло**, baseline 0.95, с затуханием хуже.
- **Почему:** в тестах сущность не там, где мы якорили затухание.

## Stage 221 — fp-adapter (матрица W) — **работает**

**Сценарий:** encoder всё же сдвинули (как если бы переучили на новом домене). Старые слоты в **старом** fp — кажется, что память «сломалась».

**Решение:** маленькая матрица **W** учится на ~800 частых слов:  
«старый fp ≈ W × новый fp». Старые ключи слотов умножаем на **W**, запрос тоже — **переиндексировать базу не обязательно**.

**Одной фразой:** encoder «поплыл» — вместо пересчёта всех слотов учим крошечную матрицу; полная W ≈ **78%** recall, узкая ≈ **70%**, идеал (oracle) ≈ **87%**.

**Важно про сценарии:** если **ключи старые**, а queries считать **новым** encoder **без W**, на нашем 4-way exam recall может остаться **~0.98** (ранги сохраняются). W нужна в протоколе 221 (старый fp + **W** на ключах и запросах), чтобы **догнать oracle**, а не «спасти от нуля».

| Что измерили | Полная W (256×256) | Узкая W (256→32→256) |
|--------------|-------------------|----------------------|
| Параметров | 65 536 | **16 384** |
| Совпадение fp на core (~800 слов) | **0.997** | **0.967** |
| Recall фактов через W @ старый ключ | **0.78** | **0.70** |
| Recall если пересчитать слоты с нуля (oracle) | **0.87** | (тот же oracle) |
| Recall **без** W после сдвига encoder | ~0.95 на старом fp* | — |

\*На **старом** fp до сдвига recall высокий; после сдвига encoder без remap — провал (см. `stage221_decision.json`).

**Два варианта W:**

- **Полная** 256×256 — чуть точнее recall (**best_remap: full** в JSON).
- **Узкая (bottleneck)** 256→32→256 — **~16k параметров**, align/recall чуть ниже, но тот же смысл: **не пересобирать всю базу слотов**.

**Простой вывод:** partial freeze внутри encoder — **нет**; **W-remap** — **да**, если encoder когда-то всё же сдвинули.

**Probe 221** (`results/stage221_probe_decision.json`, полный прогон): W ≈ **learnable warp** (WᵀW близко к I, но σ разбросаны); **OOV/hold-out** после W **~0.99 / ~0.99** при raw cos **~0.68**; **W_B ~0.83**, **W_C ~0.90** recall на одних A-слотах; **100→400** core-слов для W **сходится**; mismatch old keys + new queries без W **~0.97**.

**Концепция дальше:** [`../../results/extension_concept_after_221.md`](../../results/extension_concept_after_221.md) · **прогоны ~2 ч:** [`extension_run_queue_2h.md`](extension_run_queue_2h.md)

**222/223 (полный прогон):** лучший режим **W только на ключах + старый query (~0.73)**; new query без W **~0.18** на этом exam. **223:** «чужая W» **не хуже** matched (~0.98) — переключатель домена на 4-way пока **не доказан** (`DOMAIN_W_SWITCH_PARTIAL`).

**224 far-shift:** `W_DOMAIN_PARTIAL` — code shift самый жёсткий (cos **~0.59**); matched code W **0.88**, чужая stories W **0.68** (drop **~0.12**). Stories почти не различает wrong W. Не одна каноническая W и ещё не registry≥0.20 — **реестр имеет смысл хотя бы для code**.

**Контракт (согласовано):** [`extension_memory_contract.md`](extension_memory_contract.md) — Freeze → **W per family** (prose/code/…) + cos-триггер → Stream decay. W = **restorer**, не костыль.

**225 domain bundle:** `DOMAIN_BUNDLE_OK` — legal **reuse W_prose** (drop **−0.02**, fork=false); multi-head при frozen `arc_enc`: fp drift **0**; matched≫cross (stories **+0.33**, code **+0.70**). Shared map + `{W, head}` работает.

**227 canonical storage:** `CANONICAL_STORAGE_OK` — ключи всегда в frozen fp; лучшая политика **qmap** (W: domain→canonical на query); same **1.0**, cross-code **0.95**, drop **0.05**. Один банк + disposable W.

**226 joint gen+mem:** первый `NO` был шумом recall (SEED); **226b** — qmap **1.0** при протоколе 227; utilization ≈ граница **A**. **228a:** inject голова не читает. **228b:** `NO` (fp+global retrieve **0.40**). **228c:** `FP_DECODE_FIX_YES` — 4-way retrieve + fp-scorer **1.0** (head **0.48**); global argmax всё ещё ~**0.42**. Фикс = протокол 227, не новая линза.

**229 contradiction:** `CONTRADICTION_RAW_MEMORY_OK` — оба кандидата в top-2 **60%**.
