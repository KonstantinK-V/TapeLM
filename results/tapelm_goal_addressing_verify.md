# TapeLM — цель (адресация с проверкой)

Снято из кривой **277** (ink ≠ open semantic search) + **278** (ум читает и молчит) и формулировок «адресация с проверкой» / одна политика. Не вердикт прогона; инвариант для препринта и следующих стадий.

---

## Цель, коротко

**TapeLM:** знание живёт на ленте, ум — политика над ней. Оси независимы.

Чернила задают адресное пространство ленты. Извлечение — функция «слова запроса → ключ», а не «смысл → смысл». Мягкий канал предлагает, точный решает, ум читает и молчит, когда истины нет.

Запись — не append, а решение WRITE / CONFIRM / DISPUTE по тому же адресу. Свидетели и уверенность возникают из данных счётчиком поддержки, а не из шаблона.

Одна политика, два семейства действий, общее состояние. Лента растёт без переобучения; ум растёт репертуаром действий, а не шириной; фактов в весах нет никогда — поэтому нет и забывания.

**Инвариант, проверяемый пересборкой ленты:** кто решает — не может быть приблизительным; кто обучается — не может хранить факты.

---

## Следствия для метрик

Не top1 «семантического» ретривера. Пара: **recall@k до чтения** + **accuracy-among-answered после** (risk–coverage, как в 278). `nearest_other ≈ 0.9` — приговор системе без верификатора, не приговор адресному пространству fp.

Имя слоя: **адресация с проверкой** (retrieve-then-verify), не «семантический поиск».
